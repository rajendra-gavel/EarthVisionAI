
EarthVision AI is a satellite-image intelligence POC that analyzes before-and-after satellite imagery, identifies potential visual differences, detects supported geographic objects, and provides a natural-language AI assistant to explain the results.

The platform has a React-based dashboard, a FastAPI inference backend, computer-vision models for object detection, an experimental structural/spectral change-analysis pipeline, and a locally hosted Qwen3 model for the AI assistant.

One important design decision was to separate confirmed AI detection from experimental visual analysis. Our change-analysis approach is currently experimental, so we don't claim that every highlighted region represents real-world geographic change.


Problem Statement:
----------------
Satellite imagery contains a huge amount of information, but manually comparing images from different dates is time-consuming.

We wanted to build an AI-assisted platform that can answer questions such as:

What changed between two satellite images?
Where are potential differences?
What objects/features can be detected?
What does the analysis mean?
Can a user interact with the analysis using natural language?

So the goal is:

Convert raw satellite imagery into visual insights and natural-language explanations.

Non-functional Requirements:
---------------------------
Performance- Inference should be reasonably fast for a POC.
Scalability- Backend should be stateless so inference workers can eventually be scaled horizontally.
Security - No API secrets should be embedded in source code.
Maintainability - Separate modulerization for each components Frontend, Backend/API, AI services, Data/results
Extensibility - Models should be replaceable without redesigning the entire UI.

AI Models:
-----------------------------------------
Model 1 — YOLO26n-OBB
Used for: Aerial/geospatial object detection
It detects supported classes such as: planes,ships,storage tanks,bridges,roundabouts,swimming pools,vehicles,etc.
But does not have building class
--
Model 2 — YOLO11n
Used for: General object detection
It will detection : person,bus,car,truck,bicycle, etc
--
Model 3 — Qwen3 4B
Used for: Natural-language EarthVision Assistant
It is running locally through Ollama.
